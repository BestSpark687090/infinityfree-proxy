# infinityfree-proxy
A PHP script to make an InfinityFree domain proxy to another website.

## How to Use

1. Download/copy both the index.php and the .htaccess file. You WILL need both.

2. Open up the InfinityFree file manager to your domain. If you added another domain onto an already existing site, open the folder with the domain name, and head into the `htdocs` directory.
> If you're using the root domain, just head into the `htdocs` directory in the root.

3. Upload the `index.php` **AND** the `.htaccess` file to the same directory.
> If you just copied the file's contents, create a file with the same name in the directory and paste its contents in.

4. you done!!!
